# 江口县碳汇开发管理平台 — 需求与复刻计划

> 参考站点：[https://dnnscmrxw5.coze.site/](https://dnnscmrxw5.coze.site/)  
> 技术栈：Vue 2 + Element UI + 若依框架 + Mock 开发环境

## 1. 项目定位

面向江口县林业碳汇开发的综合管理平台，覆盖 **数据接入 → 编码翻译 → 核算入库 → 空间展示 → 多维分析 → 资产开发 → 报告输出 → 系统管控** 全业务链。

| 维度 | 说明 |
|------|------|
| 平台名称 | 江口县碳汇开发管理平台 |
| 版本 | v1.0.0 |
| 演示账号 | admin / admin123 |
| 数据类型 | Excel 台账、遥感栅格、GIS 矢量 |
| 覆盖区域 | 太平镇、德旺乡、双江街道、闵孝镇、坝盘镇、桃映镇等 |

## 3. 模块功能需求

### 3.1 登录页（P0）

- 左侧品牌区：梵净山·江口、遗产/保护区/森林覆盖率文案
- 右侧表单：账号、密码、验证码、登录按钮
- 演示账号提示：admin / admin123
- 视觉：绿色生态主题，区别于若依默认登录

### 3.2 碳汇数据台账（P0）

- 页头：标题 +「数据接入与核算结果统一管理」
- 统计：总条数、已核算、核算中、失败；累计碳汇量 (tCO₂)
- 数据上传：数据源类型、翻译表码（Excel 必选）、拖拽上传 XLSX/XLS/CSV、模板/清空
- 分类 Tab/区块：Excel、栅格影像、矢量图层
- 列表字段：上传记录、核算碳汇值、核算状态、操作（开始核算/已入库/请稍候/数据异常）
- 工具栏：筛选、导出、重置

### 3.3 翻译表配置（P0）

- 页头 +「管理数据字段的编码翻译映射规则」
- 统计卡片：翻译表总数、已启用、已停用、映射规则总数
- 筛选：全部 / 已启用 / 已停用、重置
- 表格：名称、编码、说明、映射数、状态、更新时间、查看/编辑
- 操作：新增翻译表

预置翻译表：`FOREST_TYPE`、`FOREST_SPECIES`、`LAND_USE`、`ADMIN_REGION`、`RESOURCE_LEVEL`、`DATA_SOURCE`

### 3.4 GIS 地图（P1）

- 矢量图层面板：图层名、透明度、显示开关（如 3/4 层启用）
- 地图主区域（占位/后续接 Leaflet 或 Mapbox）
- 区域详情：点击标记展示区域信息

### 3.5 碳汇分析（P1）

- 接入数据多选：Excel / 栅格 / 矢量，显示已选数量与 tCO₂ 合计
- 筛选：区域、林种、林龄；分析按钮
- 结果区：林种结构、树龄结构、优势树种、区域碳汇对比（图表/列表）

### 3.6 碳资产管理（P1）

- 筛选：区域、开发类型；查询
- 资源列表：资源 ID、区域、面积、碳汇量、开发类型（CCER/VCS/碳票）、状态、详情
- 分页
- 优先开发推荐：区域 + 潜力评分 + 推荐等级

### 3.7 报告中心（P1）

- 左侧：接入数据树（Excel/栅格/矢量）多选，全选/清空
- 已生成报告列表：标题、日期、类型、状态、数据份数
- 生成报告：报告类型选择 + 生成
- 右侧：报告详情预览区

### 3.8 系统管理（P2）

- Tab：用户管理、角色权限、日志管理
- 用户表：用户名、机构、角色、状态、操作
- 新增用户

## 4. 接口约定（Mock 阶段）

| 模块 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 台账 | GET | `/carbon/ledger/overview` | 概览统计 |
| 台账 | GET | `/carbon/ledger/list` | 分页列表，`dataType` 参数 |
| 翻译表 | GET | `/carbon/translation/stats` | 统计 |
| 翻译表 | GET | `/carbon/translation/list` | 列表 |
| GIS | GET | `/carbon/gis/layers` | 图层 |
| 分析 | GET | `/carbon/analysis/datasets` | 可选数据集 |
| 分析 | POST | `/carbon/analysis/run` | 执行分析 |
| 资产 | GET | `/carbon/assets/list` | 资源列表 |
| 资产 | GET | `/carbon/assets/recommend` | 开发推荐 |
| 报告 | GET | `/carbon/reports/list` | 已生成报告 |
| 报告 | GET | `/carbon/reports/datasets` | 接入数据 |
| 系统 | GET | `/carbon/system/users` | 用户列表 |

接口层仅封装 HTTP，业务数据放 `mock/data/carbon/`。

## 6. 验收标准

- [ ] 登录页视觉与参考站一致度 ≥ 80%
- [ ] 7 个业务菜单可访问，页面布局与参考站功能对齐
- [ ] 列表/统计/筛选交互可用，数据来自 Mock 非页面硬编码
- [ ] `VUE_APP_MOCK=true` 下无需后端即可完成演示
